# プロフィールページの自己紹介・経歴・資格情報の充実

## 目的・背景

- 採用担当者に対し、Webディレクター経験を背景としたAI駆動型フルスタックエンジニアとしての強み、現在の活動、詳細な職務経歴、保有資格を伝える。
- 既存の簡易的なプロフィール内容（自己紹介文1行、空欄の経歴表、技術タグのみ）を、具体的な経歴・実績を伝えられる内容に更新する。

## 利用者

- 主に採用担当者・企業の採用関係者を想定する。

## 必要な挙動

- プロフィールページの自己紹介文を更新する。
- プロフィールページに「現在の活動（プログラミングコーチ）」セクションを表示する。
- プロフィールページの経歴表示を、時系列の職務経歴（期間・業務内容・強み）に更新する。
- プロフィールページのスキル表示を、保有資格・スキル証明の一覧に差し替える。

## 受け入れ条件

- [ ] プロフィールページで、自己紹介文（Webディレクションの視座を持つAI駆動型フルスタックエンジニアとしての説明）を閲覧できる。
- [ ] プロフィールページで、現在の活動（プログラミングコーチ、活動期間、業務内容）を閲覧できる。
- [ ] プロフィールページで、職務経歴が期間ごとに区切られ、各期間の業務内容を閲覧できる。
- [ ] プロフィールページで、保有資格・スキル証明の一覧を閲覧できる。
- [ ] プロフィールページがスマートフォン・PCの両方で適切に表示される。

## 対象外

- 制作実績一覧のプロフィールページへの統合（Issue #13で別途対応）
- 開発プロセスページ（process.blade.php）の文言・構成変更（別途要件化）
- 職務経歴書（PDF）のダウンロード機能（別途対応）

## 制約

- アプリケーション構成はLaravel単体（Blade + Tailwind CSS）とする。
