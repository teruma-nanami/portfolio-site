# 制作・運用実績セクションおよび職務経歴書欄の修正

## 目的・背景

- 本ポートフォリオサイトはすでに職務経歴書として採用担当者へ共有済みであり、リンク切れや実績情報の不足を早急に修正する必要がある。
- 制作・運用実績セクション内のリンク切れ・実績情報の不足を解消し、実際にログインして動作確認できる状態にする。
- 職務経歴書PDFに個人情報が含まれるため、公開を停止する。
- Issue駆動開発で作成した実績（本ポートフォリオサイト・英単語クイズアプリ）を他の実績と区別して表示し、開発プロセスへのアピール力を高める。

## 利用者

- 主に採用担当者・企業の採用関係者を想定する。

## 必要な挙動

1. 自己紹介文中の「開発プロセス」リンク、および制作・運用実績内の「開発プロセス詳細」リンクを、実際に存在する開発プロセスページ（`/process`）へ正しく遷移するよう修正する。
2. 「独自機能拡張Webメディア」の実績に、運用中サイトへの外部リンクを2件追加する（`https://dimension-girl.com/`、`https://yu-gi-ou.dimension-girl.com/`）。
3. rese・フリマアプリ・atteの実績カードに、確認用ログインID・パスワードをそれぞれ平文で表示する。
   - rese：email `admin@example.com` / password `password`
   - フリマアプリ：email `admin@example.com` / password `password`
   - atte：email `yoshimoto.manabu@example.com` / password `password`
4. 職務経歴書のダウンロードセクション（説明文・ダウンロードボタン）をページから削除する。

## 受け入れ条件

- [ ] 自己紹介文中の「開発プロセス」リンク、および制作・運用実績内の「開発プロセス詳細」リンクをクリックすると、開発プロセスページ（`/process`）が表示される。
- [ ] 「独自機能拡張Webメディア」の実績から、`https://dimension-girl.com/` と `https://yu-gi-ou.dimension-girl.com/` の両方へ遷移できる。
- [ ] rese・フリマアプリ・atteの実績カードで、それぞれの確認用ログインID・パスワードが閲覧できる。
- [ ] 職務経歴書のダウンロードセクションがページに表示されない。
- [ ] 各修正後もページがスマートフォン・PCの両方で適切に表示される。

## 対象外

- サイト全体のデザイン・配色などのモダン化（別途要件化予定）
- 制作・運用実績の表示グループ分け・見出し追加などの表示構成変更（Issue #20「デプロイ前に全ページの表示を微調整する」で対応）
- rese・フリマアプリ・atte以外の実績（乗り換えログ、英単語クイズアプリ）へのログイン情報追加
- 職務経歴書の内容そのものの変更、およびPDFファイルの削除（PDFファイルは未作成のため対象外）

## 制約

- アプリケーション構成はLaravel単体（Blade + Tailwind CSS）とする。
- 既存の他の実績カード（rese、フリマアプリ、Atte、乗り換えログ、本ポートフォリオ、英単語クイズ）のリンク先URLは変更しない。
