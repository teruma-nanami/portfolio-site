# 制作実績一覧ページの廃止とプロフィールページへの統合

## 目的・背景

- ナビゲーションのページ数を減らしてサイト構成をシンプルにする。
- 採用担当者がプロフィールページ1画面で経歴・スキル・制作実績を一貫して評価できるようにする。

## 利用者

- 主に採用担当者・企業の採用関係者を想定する。

## 必要な挙動

- 制作実績一覧ページ（`/works`）を廃止する。
- 制作実績の一覧（タイトル・概要・外部詳細URLへのリンク）を、プロフィールページ内に表示する。
- ナビゲーションから「制作実績」へのリンクを削除する。
- `/works`へのルート定義を削除する。

## 受け入れ条件

- [ ] `/works`にアクセスすると、ページが存在しない（404）。
- [ ] ナビゲーションに「制作実績」へのリンクが表示されない。
- [ ] プロフィールページ内で、制作実績のタイトル・概要が一覧表示され、各項目から外部の詳細URLへ遷移できる。
- [ ] プロフィールページがスマートフォン・PCの両方で適切に表示される。

## 対象外

- 制作実績データそのものの内容変更（実績の追加・削除・URL変更）
- プロフィールページの職務経歴・資格などの加筆内容（既存の別作業として扱う）
- 制作実績データのDB化・管理画面化

## 制約

- アプリケーション構成はLaravel単体（Blade + Tailwind CSS）とする。
- 既存の制作実績の外部リンク先URLは変更しない。

## 未決事項
